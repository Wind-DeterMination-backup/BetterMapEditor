# src 层说明

## 这一层负责什么
`src/` 是项目源码总入口。Gradle 按约定从这里寻找各个 source set 的代码与资源。本仓库只使用了标准的 `main` source set，没有测试源集和额外变体。

## 本层内容

- `main/`
  生产代码层。模组运行时真正会被打包进去的 Java 类和资源都放在这里。

## 为什么只保留 main

- 这是一个体量较小、目标单一的模组，当前没有单元测试、数据生成器或多平台源码分叉。
- 结构保持标准 Gradle 布局，IDE 和构建工具零配置即可识别。

## 与其他层级的关系

- 上游由根层 `build.gradle` 声明为默认源目录。
- 下游分成 `java/` 和 `resources/` 两条并行支线。
- 构建时两者会被统一打包进最终模组文件。
