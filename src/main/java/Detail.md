# src/main/java 层说明

## 这一层负责什么
这一层是模组的运行时代码层，承担真正的行为实现。所有地图编辑器增强、UI 挂接、反射兼容、更新检查都从这里进入游戏。

## 包结构

- `bettermapeditor/`
  模组自有命名空间，负责入口、功能装配、辅助服务。
- `mindustry/`
  与上游同名的镜像包路径，用来放置需要与 Mindustry 内部类型深度耦合的扩展类。

## 为什么要分成两个命名空间

- `bettermapeditor` 负责“这是我的模组逻辑”。
- `mindustry` 负责“这段实现需要看起来像上游滤镜生态的一部分”。
- 这种分层让主业务和对上游类的侵入式适配分开，便于理解哪些代码是正常功能，哪些代码是在补足或替换原版行为。

## 核心技术手段

- 事件监听：在客户端加载完成和每帧更新时挂接逻辑。
- 反射：访问 `MapGenerateDialog` 的私有字段与方法，替换滤镜列表并刷新预览。
- 包路径兼容：自定义滤镜类放到 `mindustry.maps.filters`，减少与原版体系的语义距离。

## 与其他层级的关系

- 上层 `src/main/` 指定这里的内容会被编译。
- 下层 `bettermapeditor/` 提供入口与编排，`mindustry/` 提供底层滤镜实现。
- 本层依赖 `src/main/resources/bundles` 提供设置项文案和模组描述文本。
