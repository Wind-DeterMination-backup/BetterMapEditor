# bettermapeditor.filters 层说明

## 这一层负责什么
当前这一层没有放任何源码文件，属于预留命名空间。它的存在说明项目结构曾考虑过把自定义滤镜放在模组自有包下，但最终实际采用了另一种实现策略。

## 为什么会是空目录

- 当前核心滤镜类 `DraggableMirrorFilter` 被放在 `mindustry.maps.filters`，这样更贴近原版 `MirrorFilter` 的语义位置。
- 对于阅读者来说，这个空目录本身也是信息：作者把“功能编排”与“滤镜底层实现”分开思考过，只是最终没有在这里落地。

## 对整体结构的意义

- 它提醒后续维护者，这里可以作为未来新增自定义滤镜或适配器类的容器。
- 它也反衬出当前设计选择的重点不在“新建一套滤镜体系”，而在“对原版镜像滤镜做兼容式增强”。

## 与其他层级的关系

- 上层属于 `bettermapeditor` 主包。
- 当前没有下层内容。
- 真正的滤镜实现落在平级但不同根命名空间的 `mindustry/maps/filters/`，这是本项目一个值得特别说明的结构决策。
