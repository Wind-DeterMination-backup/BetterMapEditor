# mindustry.maps 层说明

## 这一层负责什么
这一层是地图生成相关适配层，把对上游 `mindustry.maps` 体系的扩展集中起来。当前项目只增强了滤镜，因此这里继续向下收敛到 `filters/`。

## 为什么单独保留这一层

- 它明确表明修改目标是地图模块，而不是整个游戏客户端。
- 在包路径上保留完整层级，可以让最终类名与上游结构保持一致，减少维护时的认知跳跃。

## 当前职责边界

- 不存放编辑器 UI 入口代码，那部分在 `bettermapeditor.features`。
- 不存放模组设置和更新检查，那部分在 `bettermapeditor` 主包。
- 只作为地图滤镜扩展的语义中间层存在。

## 与其他层级的关系

- 上层 `mindustry/` 表示这是对上游包结构的局部映射。
- 下层 `filters/` 才是实际代码所在位置。
- 这一层本身没有文件，但通过目录层级把职责范围限定在“地图滤镜增强”。
