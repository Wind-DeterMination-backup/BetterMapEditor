# src/main/resources 层说明

## 这一层负责什么
这一层是运行时资源层，用来放不会被 Java 编译器处理、但会被打包进模组并在运行时按路径读取的资源文件。

## 本层内容

- `bundles/`
  本地化资源目录，存放模组名称、描述、设置项标题与说明。

## 为什么资源层重要

- 仓库约束明确要求用户可见文案优先走资源文件，不硬编码。
- Mindustry 自带 bundle 机制，设置界面和模组元数据展示都可以从这里拿文本。
- 把中英文放在资源层，可以让功能代码只关心 key，不关心具体语言内容。

## 与其他层级的关系

- 上层 `src/main/` 把这里与 `java/` 并列管理。
- 下层 `bundles/` 提供真正的文本条目。
- `bettermapeditor.BetterMapEditorMod` 和设置 UI 通过 key 引用这里的字符串。
