# src/main 层说明

## 这一层负责什么
`src/main/` 是 Gradle 默认生产源集的落地目录。它的意义不是“功能分类”，而是“打包边界”：放在这里的内容会进入最终模组，不放在这里的内容默认不会。

## 子层划分

- `java/`
  放 Java 源码，编译后变成 `.class`。
- `resources/`
  放资源文件，构建时原样复制进入产物。

## 实现特点

- Java 逻辑和资源文本并列，不把文案硬编码进类文件，符合仓库的资源化约束。
- 这种布局直接复用 Java/Gradle 生态的默认行为，不需要自定义 sourceSets。

## 与其他层级的关系

- 上层是 `src/` 的唯一活跃 source set。
- 下层的 `java/` 负责行为实现，`resources/` 负责名称、描述、设置项文本。
- 两者最终在 `dist/` 中重新汇合成同一模组包。
